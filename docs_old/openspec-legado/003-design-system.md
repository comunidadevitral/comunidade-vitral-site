# 003 — Design system

## Diretrizes
- Mobile-first
- Tipografia legível
- Componentes simples: header, footer, cards, CTA
- Sem frameworks pesados

## Paleta
Tokens padrão:
- deep-navy
- warm-sand
- cta-teal
- sage-green
- dusk-rose
- gray-light
- gray-text

## SEO
- Title e description por página
- URL canônica
- Open Graph básico
- Imagens com alt e lazy-loading

## Performance
- HTML/CSS leve
- JS mínimo
- Assets otimizados
