# 004 — Deploy

## Estratégia
- Repositório próprio no GitHub
- GitHub Pages como hosting
- Branch `homologacao` para desenvolvimento
- Branch `main` para produção

## Passos
1. Criar repo `comunidadevitral`
2. Push inicial da estrutura
3. Implementar site estático em `src/`
4. Testar build e preview
5. Ativar GitHub Pages em `main`
6. Validar conteúdo e layout com usuário
7. Deploy final

## Rollback
- Reverter commit no GitHub caso necessário
- Pages reflete branch `main` imediatamente
